ExSeq Brain AD — analysis data (ExSeq / Xenium)

Spatial transcriptomics analysis tables and Xenium Ranger HTML reports from the ExSeq Brain AD study (wild-type and 5xFAD mouse hippocampus).

This deposit provides the large input files used by the MATLAB expression / Moran’s I / full-section analyses. Companion code, scripts, and web explorer are published separately:

  • Code / repository: https://doi.org/10.5281/zenodo.17568649
  • GitHub: https://github.com/yaara-dev/early-AD-data-code
  • Interactive ExSeq data explorer: https://yaara-dev.github.io/early-AD-data-code/

Contents

The archive unpacks to four folders. Place them under data/ in the code repository (so you get data/exseq/, data/xenium/, etc.):

FolderContents
exseq/ Joined ExSeq transcript CSVs for MATLAB analyses (16 samples: WT_1–WT_6.2 and 5xFAD_1.1–5xFAD_6.2)
xenium/ Xenium hippocampus transcript CSVs (WT_5, WT_6_section1/2, 5xFAD_5_section1/2, 5xFAD_6)
xenium_full_sections/ Xenium full-section Parquet tables (same animals/sections as above)
xenium_html/ Self-contained Xenium Ranger analysis-summary HTML reports (open in a browser; also included in the code deposit)

How to use

  1. Clone or download the code archive: https://doi.org/10.5281/zenodo.17568649
  2. Download this data archive and unpack into the repository’s data/ directory.
  3. Run the MATLAB scripts under analysis_scripts/expression_spatial_distribution_morans_i/. They already point at data/exseq/, data/xenium/, and data/xenium_full_sections/.

For column schemas and sample lists, see data/README.md in the code repository.

Xenium samples (published names)

WT: WT_5, WT_6_section1, WT_6_section2
5xFAD: 5xFAD_5_section1, 5xFAD_5_section2, 5xFAD_6

Multi-section animals use _section1 / _section2 suffixes. Single-section animals (WT_5, 5xFAD_6) have no section suffix.
